## 5b. SwitchBench-natural v1 (build-out, proposed 2026-09-26)
**Status: APPROVED by Colin 2026-09-26 ("Criteria approved"), frozen at this commit. TESTING.** v0 passed its frozen rule (results/switchbench_natural.md), but the claim is not yet release-grade. v1 hardens it before any public claim. Colin's scope: bigger corpus, stronger labels, fair detector coverage, second-scroll replication. Release target Oct 5-8; date wins over scope.

Facts behind this draft: est. label precision ~0.70 (9.6 um CT; 4.8 um reads did not help in v0). 10 of 54 events sit in one patch. tifxyz-doctor stores bare alarm locations with no cue, and three patches carry more than 50 alarms (57, 55, 104), so a per-cue cap of 50 may have hidden hits. windaudit and windcheck were mostly silent by construction. HF spiral/ holds verified and unverified traces only for PHercParis4 (0139, 0332 and 1451 have fibers only).

### Pre-registered criteria (skeptic, 2026-09-26, APPROVED)
| Item | Specification |
|------|---------------|
| Corpus | Same seeded order (seed 20260925) over PHercParis4 unverified patches, continuing past the v0 prefix: patches 3,001 to 10,000. The in-sample rule and event definition are v0's as finally run (D1, D4, D5 fixes frozen as rules). The pooled corpus is v0 + new. Every headline number is also reported on the new patches alone (a within-scroll holdout). |
| Per-patch cap | At most 3 events per patch count toward recall (seeded pick). Uncapped reported as sensitivity. |
| Labels: 2.4 um CT | Re-confirm every candidate with level-0 (2.4 um) numeric CT profiles. The rule constants are tuned only on human ladder controls (relative_windings.json), as in v0 D8; no corpus data enters the tuning. Report the ladder rates: adjacent-pair pass, two-apart false pass, same-sheet false pass. |
| Labels: strong or not | STRONG if the ladder false-pass rates are both <= 5% and adjacent pass >= 70%. Otherwise a **blind review by Colin** is triggered: 30 seeded locations (15 confirmed events, 10 CT-contradicted candidates, 5 negative runs), order shuffled, labels hidden. Colin marks switch / no switch / can't tell in VC3D (about 1 hour). Measured precision = confirmed events marked "switch" / confirmed events marked either way (Wilson 95% CI). |
| Detectors, primary | Defaults at pinned commits, as v0. **tifxyz-doctor runs uncapped** (raise or remove the per-cue example cap if the CLI allows; otherwise record per-cue counts and flag every patch with a capped cue). |
| Detectors, secondary (labeled "author-intended mode") | windcheck at the smallest min-cells its docs allow. windaudit with the attachment gap widened per its docs. sheet-topo-bench via an input adapter if it can be built within 1 day, else "not run" with the reason. Reported beside defaults; never replaces them. |
| C1 headline test | tifxyz-doctor natural recall on confirmed events, patch-block bootstrap 95% CI (B = 2000, seed 20260925), per-patch cap 3. **Precision-corrected upper bound** = CI upper / precision lower bound (measured if blind review ran, else the ladder mixture estimate). **SUPPORTED** if the corrected upper bound < 0.60 on the pooled corpus AND on the new patches alone. **FAILS** if the CI lower bound > 0.85. Otherwise INCONCLUSIVE: release as dataset + descriptive numbers only, with Colin's approval. |
| C2 coverage | Per tool, both modes: recall (95% CI), false alarms per 100 mm, patches with a verdict. Any tool with intended-mode natural recall CI lower bound >= 0.80 is reported as "handles natural switches". That weakens the headline and is reported anyway. |
| C3 early warning | gen_avg_cost AUROC as in v0 (report only). |
| C4 second scroll | Scout checks public sources beyond HF spiral/ (S3 segment trees, community mesh sets) for a scroll with auto-grown traces, reference surfaces and CT. PHerc0332 is excluded (the org's active ink frontier). If feasible by Oct 1: same pipeline, report-only replication (non-replication is reported). If not: logged "not feasible in time" and shipped later as an update. |
| Sensitivity | Matching radius 0.5 / 1 / 2 mm. v0 prefix vs new patches. Uncapped per-patch events. Random alarms at the doctor's density. |
| Sanity (failure = harness bug, no verdict) | S1 to S3 re-run on the v1 harness, including the 2.4 um rule. S4: the uncapped doctor run reproduces every v0 hit on the 69 v0 doctor patches (regression). |
| Caps | Corpus closes 2026-09-30 23:59Z (whatever exists is the corpus). All v1 analysis closes 2026-10-03 23:59Z, then packaging. $0, CPU only. Disk <= 10 GB. Hours logged in LEDGER.md. |
| Prior art | Scout re-checks before release. If a public natural-switch recall benchmark appears first, "first" is dropped from every claim and v1 ships as an independent replication. |
| Rules | No ink maps, numeric CT only, no images. Tool authors are contacted the same day as the prize submission. |
